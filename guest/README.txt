Arlinux Arch ARM

启动后默认进入 OpenCode Desktop。点击右侧竖条显示或隐藏微信输入法，
长按竖条可以把微信输入法的语音结果发送给 OpenCode。

默认包含 Arch Linux ARM 和 Arch Linux 中文社区软件源，均使用清华镜像。
在 OpenCode 的终端工具或终端应用中安装软件：
  pacman -Syu
  pacman -S 软件包名

OpenCode 已预置 Linux 无障碍自动化说明和异步中文语音进度播报能力。
软件源配置：/etc/pacman.conf 和 /etc/pacman.d/mirrorlist

This APK runs Arch Linux ARM userspace on the Android kernel.
The package database and your home directory belong to this APK.
