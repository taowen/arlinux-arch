Arlinux Arch

The default session opens OpenCode Desktop. Use pacman from its terminal tools
or from a terminal application:

  pacman -Syu
  pacman -S package-name

Repository configuration is stored in /etc/pacman.conf and
/etc/pacman.d/mirrorlist. The session includes Linux desktop accessibility and
asynchronous online progress speech.

Android supplies the display, input, audio, network, and application lifecycle.
